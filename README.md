# Flixpense AI — AI Expense Tracker

An AI expense tracker built using FastAPI, React, Vite, SQLite, Hugging Face, and Tesseract.js OCR.

## Live Demo

**Live Website:** https://ai-expense-tracker-jdld.onrender.com

## Features

- Track and manage expenses.
- Analyze spending with dashboards and charts.
- Use AI-powered expense assistance.
- Scan receipts using OCR.
- Manage budgets and view expense summaries.

## Tech Stack

- **Frontend:** React, Vite, JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **AI:** Hugging Face
- **OCR:** Tesseract.js

## Run Locally

1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Configure the required environment variables.
4. Start the FastAPI backend and React frontend.

## Note

The live demo may take some time to load because the application is hosted on Render's free service tier.
